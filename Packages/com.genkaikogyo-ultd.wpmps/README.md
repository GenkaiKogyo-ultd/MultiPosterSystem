# MultiPosterSystem

- MultiPosterSystem は、VRChat 上のワールドに設置するポスターのギミックです。
- 以下の機能を有しています。
  - 複数のポスターを順番に表示する機能。
  - ポスターをクリックした時に特定のグループページを表示する機能。
  - ポスターのデータを動画データの形で外部から読み込む機能。
    - ワールドの再アップロードを行うことなく、ポスターの追加が可能です。
- ポスターの動画データを作成・アップロードする際には、[MultiPosterSystem DataBuilder-Template][1]を利用すると便利です。

[1]: https://github.com/GenkaiKogyo-ultd/MultiPosterSystem-DataBuilder-Template
